## 1. Резюме

«Гео Разум» — сервис автоматического анализа земельных участков: по кадастровым
данным, 15+ государственным реестрам и спутниковым снимкам система за **10 минут**
формирует PDF-отчет: скрытые ограничения, борщевик и свалки, инфраструктура,
инвестиционная концепция и финансовая модель (NPV, IRR, окупаемость).

К настоящему моменту реализован **интерактивный прототип** продукта, который
демонстрирует весь пользовательский путь целиком. Настоящее предложение —
вывод прототипа в промышленную эксплуатацию: бэкенд, реальные источники данных,
онлайн-оплата и автоматическая генерация отчетов.

Демо-версия сервиса доступна по ссылке: [index.html](index.html).

## 3. Архитектура целевого решения

```
Браузер (лендинг, заказ, ЛК)  ──►  API (REST)
                                     ├─ Сервис заказов и биллинга
                                     ├─ Сервис отчетов (генератор PDF)
                                     ├─ Аналитический сервис (GIS + CV)
                                     ├─ Админ-панель
                                     └─ B2B API (модули «Агро», «ЭкоКонтроль», «Земельный Банк»)
Источники данных:
  ЕГРН / Росреестр · ФГИС ТП · ИСОГД · лесной реестр · спутниковые снимки
```

- **Бэкенд**: рекомендуем [Python/FastAPI или Node.js — по решению заказчика],
  REST API, документация OpenAPI.
- **БД**: PostgreSQL + PostGIS (пространственные данные, гео-запросы).
- **Оплата**: онлайн-эквайринг (ЮKassa / Сбербанк / CloudPayments), хранение
  карт не требуется — полный PCI DSS не нужен.
- **Отчеты**: шаблонизация PDF (WeasyPrint/reportlab), картографические
  приложения к отчету (снимок + слои ограничений).
- **Хостинг**: облако (Yandex Cloud / VK Cloud), CI/CD, мониторинг, бэкапы БД.
- **Мобильная версия**: адаптивна с текущего прототипа, отдельные приложения —
  вне рамок данной сметы.

## 4. Состав работ по этапам

### Этап 1. Инфраструктура и бэкенд
- Проектирование БД, деплой-контур (dev/stage/prod), CI/CD.
- API: пользователи, заказы, отчеты, платежи, тарифы; админ-панель.
- Регистрация/вход, восстановление пароля, роли (клиент, админ).

### Этап 2. Источники данных
- Интеграция с публичными и коммерческими API: ЕГРН/Росреестр, ФГИС ТП,
  ИСОГД (по региону), лесной реестр.
- Очередь запросов, кэширование, дедупликация, юридическое сопровождение
  договоров на данные.
- Спутниковые снимки: Sentinel-2 (бесплатно) + коммерческие снимки высокого
  разрешения (0,3–0,5 м) у выбранного провайдера.

### Этап 3. Аналитика и генерация отчетов
- Компьютерное зрение: детекция борщевика, свалок, зарастания, застройки,
  эрозии по снимкам.
- Расчеты: охранные зоны, приаэродромные территории, удаленность до дорог и
  сетей (дорога/электричество/газ/вода), свободная площадь под застройку.
- Генератор PDF: 4 шаблона по ролям (дачник / риэлтор / инвестор / юрист),
  финансовая модель (NPV, IRR, срок окупаемости) для инвестора.

### Этап 4. Оплата и личный кабинет
- Онлайн-оплата картой, баланс, пополнение, история платежей и заказов,
  чеки (54-ФЗ через оператора).
- Email-уведомления: отчет готов, квитанции, промокоды.

### Этап 5. B2B API
- Открытый API для B2B-клиентов: мониторинг зарастания земель («Гео Разум
  Агро»), экологический контроль («ЭкоКонтроль»), поиск заброшенных объектов
  («Земельный Банк»).
- API-ключи, тарификация, лимиты, документация и песочница.

### Этап 6. Запуск
- Комплексное тестирование, нагрузочные тесты, приемка.
- Деploy, мониторинг, документация, передача кода и доступов.
- Гарантийная поддержка 6 месяцев.

## 5. Команда и сроки

Рекомендуемый состав: проджект-менеджер/аналитик (частично), 1 тимлид-бэкенд,
1 frontend, 1 GIS-инженер, 1 ML-инженер (компьютерное зрение), 1 QA.

| Этап | Срок (раб. дни) | Результат |
|---|---|---|
| 1. Инфраструктура и бэкенд | 15 | Рабочий API, админка, auth |
| 2. Источники данных | 20 | Реальные данные по кадастровому номеру |
| 3. Аналитика и отчеты | 25 | Автогенерация PDF по всем 4 ролям |
| 4. Оплата и ЛК | 10 | Прием платежей, история заказов |
| 5. B2B API | 15 | Публичный API с документацией |
| 6. Тестирование и запуск | 10 | Продакшн, приемка, поддержка |

**Итого: ~95 рабочих дней (4–5 месяцев)** при работе параллельными потоками.

## 7. Что не входит в стоимость

- Стоимость данных: спутниковые снимки высокого разрешения, платные API

- Депозиты/абонентская плата облачного провайдера, домен, SSL.
- Разработка мобильных приложений.
- Юридическое сопровождение получения разрешений на данные (при
  необходимости — дополнительно).
