# Дизайн-система «Гео Разум»

Референс — приложенный пользователем скриншот корпоративного дашборда.
**Основные цвета сайта: голубой и зелёный** (требование пользователя, сильнее
любых других соображений).

## Палитра

```css
:root {
  --blue: #1f9ad6; /* основной голубой */
  --blue-dark: #1677b3; /* hover/акцент */
  --green: #2e9e5b; /* основной зелёный */
  --green-dark: #237a46; /* hover/акцент */
  --grad: linear-gradient(90deg, #1f9ad6, #2e9e5b); /* фирменный градиент */
  --bg: #f2f5f8; /* фон контентной области */
  --card: #fff;
  --border: #e2e8f0; /* рамки карточек */
  --text: #1c2632;
  --muted: #66727f;
  --sidebar: #232f3e; /* тёмный сайдбар */
  --sidebar-2: #1b2531; /* более тёмный (футер сайдбара) */
  --danger: #e05252;
  --warn: #d98b1f;
}
```

Семантика: голубой — основные действия, ссылки, акценты; зелёный — успех, «Готово»,
галочки, деньги; градиент голубой→зелёный — фирменный элемент (лого, баннеры, CTA).
Красный — только негативные действия/ошибки.

## Референс: каркас дашборда

```
┌──────────────┬──────────────────────────────────────────┬──────────────────┐
│  Сайдбар     │  Контент (--bg #f2f5f8)                  │  ┌──────────────┐ │
│  ~280px      │  Заголовок + действия                     │  │ Недавние     │ │
│  --sidebar   │  ┌──────────┐ ┌──────────┐ ┌──────────┐  │  │ события      │ │
│  ─────────── │  │ карточка │ │ карточка │ │ карточка │  │  │ (белая       │ │
│  лого        │  │ «Актуаль-│ │          │ │          │  │  │  панель)     │ │
│  пользователь│  │ ные      │ │          │ │          │  │  │ ● иконка…    │ │
│  счёт        │  │ заказы»  │ │          │ │          │  │  │ ● иконка…    │ │
│  CTA-кнопка  │  └──────────┘ └──────────┘ └──────────┘  │  │ «Посмотреть  │ │
│  ─────────── │  сетка карточек: статус (серый            │  │  все события»│ │
│  навигация   │  uppercase) + зелёная галочка-кружок      │  └──────────────┘ │
│  (иконки)    │                                          │                  │
│  ─────────── │                                          │                  │
│  вторичная   │                                          │                  │
│  CTA         │                                          │                  │
└──────────────┴──────────────────────────────────────────┴──────────────────┘
```

Детали референса:

- **Сайдбар** `--sidebar`: лого сверху; блок пользователя; блок счёта; акцентная
  CTA; навигация с иконками — активный пункт светлее + левая акцентная полоса;
  внизу вторичная CTA на `--sidebar-2`.
- **Карточки**: белые, `border: 1px solid #e3e8ef`, радиус 4–6px, тень лёгкая
  (или без), внутри заголовок + контент.
- **Статусы**: маленький серый uppercase-текст; «Готово» — зелёная галочка в
  кружке.
- **Кнопки**: синяя заливка (primary), красная (негатив), светло-серая (ghost).
- **Типографика**: чистый sans — Roboto / Segoe UI, базовый размер 14–16px;
  заголовки крупные (20–32px), жирные.

## Компоненты (реализованы)

### UI-кит (`shared/ui`)

`Button` (variants: primary/gradient/ghost/danger/outline), `Input`, `Textarea`,
`Select`, `Checkbox`, `Field` (метка + ошибка), `Card`, `Tabs` (для табов ЛК и
админки), `Spinner`/`Loading`, `Alert`, `EmptyState`, `StatCard`, `Table`.

### Иконки (`shared/icons`) — SVG как React-компоненты

`logo.tsx` (лого + логотип для сайдбара), `nav.tsx` (навигация: заказы, отчёты,
платежи, документы, уведомления, поддержка, админка…), `actions.tsx` (плюс,
стрелки, копирование, печать/PDF, повтор, поиск, фильтры…), `status.tsx`
(часы, галочка, ошибка, предупреждение…).

### Виджеты (`widgets`)

| Компонент             | Где                     | Описание                                                                  |
| --------------------- | ----------------------- | ------------------------------------------------------------------------- |
| `Header` / `Footer`   | Публичные страницы      | Лого, меню, «Войти»/аватар; футер: контакты, документы, реквизиты         |
| `SidebarLayout`       | ЛК и админка            | Тёмный сайдбар + контент по референсу                                     |
| `LevelCard`           | Главная, Уровни, Тарифы | Карточка S/M/L: описание, результаты, срок, цена, «Подробнее», «Заказать» |
| `StatusBadge`         | Везде                   | Статус заказа: серый uppercase, зелёный при «Готово», тона blue/red/warn  |
| `RecentEvents`        | ЛК                      | «Недавние события» из уведомлений (по референсу)                          |
| `ReportView`          | Отчёт                   | Рендер структуры отчёта по уровню + стиль печати                          |
| `OrderCard`, `Admin*` | ЛК / админка            | Карточка заказа, таблицы админки, блоки статистики                        |

### Фичи (`features`)

`auth` (SignIn/SignUp/Recovery-формы), `order-wizard` (5 шагов), `pay`
(PayForm + валидация карты), `order-actions` (Retry/Resend/DownloadReportLink),
`feedback`, `profile` (смена данных/пароля), `admin/forms`
(LevelForm/OrderStatusForm/UserBlockButton/OfferForm).

## Маршруты клиента (реализовано)

Все маршруты ниже реализованы в `client/src/app/App.tsx` (React Router v7).
Защищённые — через `Protected` (редирект на `/login`), админка — `AdminOnly`
(редирект на `/cabinet`). Табы ЛК и админки — query-параметр `?tab=`.

```
/                    Главная (8 блоков, п. 3.2 ТЗ) — PublicLayout
/about               О сервисе
/levels              Уровни S/M/L (якоря #level-s/m/l)
/tariffs             Тарифы
/examples            Примеры отчётов (демо GET /api/examples/report + печать)
/documents           Документы (оферта, политика, возвраты; ?doc=)
/contacts            Контакты + форма обратной связи
/login, /register, /recovery
/order               Визард заказа (защищён, 5 шагов)
/order/:id           Статус генерации (поллинг 2 с)
/order/:id/pay       Оплата картой
/order/:id/report    Отчёт (печать) — защищён, без шапки/футера
/cabinet             ЛК, табы: overview, orders, reports, payments, documents, profile, support
/admin               Админка, табы: overview, orders, users, tariffs, generations, offer
*                    NotFound
```

## Страница отчёта (стиль печати)

Отчёт — это HTML-страница с структурированными разделами. Кнопка
«Скачать PDF» = `window.print()`. В `@media print` скрывать сайдбар/шапку/
кнопки, использовать белый фон, чёрный текст. Лого и реквизиты — в шапке.
Открывается по `/order/:id/report` (для pdf-загрузки из ЛК/админки — тот же
роут, клиент сам решает, открыть ли страницу).

## Тонкости

- Не использовать старый фирменный зелёный `#0f8a5f` в чистом виде (был в
  старом макете) — только `--green: #2e9e5b`.
- Кнопки на градиенте: белый текст; hover — `--blue-dark`/`--green-dark`.
- Формы: метки сверху, поля с рамкой `--border`, фокус — голубая обводка.
- Пустые состояния: иконка + текст `--muted` + CTA.
