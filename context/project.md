# Проект «Гео Разум»

## Суть

Сервис формирования **аналитического заключения по земельному участку** по
кадастровому номеру. Пользователь выбирает уровень анализа, оплачивает картой,
сервис асинхронно собирает отчёт и выдаёт PDF. ТЗ: `ГР ТЗ сайт.docx` в корне
репозитория.

## Продуктовые блоки ТЗ

- **Уровни анализа S/M/L** (п. 5): разные наборы разделов отчёта, сроки, цены.
- **Регистрация/авторизация** (п. 4): имя, фамилия, email, телефон, пароль,
  согласия `consentPd` + `consentTerms`; подтверждение email — мок (авто).
- **Заказ** (п. 6): кадастровый номер, для L — 7 инвест-полей; акцепт оферты с
  фиксацией версии и времени (п. 7.1).
- **Оплата** (п. 7.2): мок платёжной сессии, карты, чек, повторная оплата.
- **Генерация отчёта** (п. 8): 10 статусов, повторный запуск, PDF (в демо —
  печать страницы отчёта).
- **Личный кабинет** (п. 10): обзор, заказы, отчёты, платежи, документы,
  профиль, поддержка; запрос удаления аккаунта.
- **Админка** (п. 11): пользователи, заказы, тарифы, оферта, мониторинг
  генераций, статистика.
- **Уведомления** (п. 12): пользователю и админам, мок-письма в `db.emails`.

## Состав отчёта по уровням

- **S**: 6 разделов — правовой статус, градостроительные параметры, ограничения
  и обременения, транспорт, инженерные сети, пространственные данные +
  «Рекомендации и дорожная карта».
- **M**: добавляет групповую застройку и анализ смежных участков.
- **L**: добавляет инвестпотенциал, сценарии освоения, финмодель (CAPEX 109,2 млн
  ₽, NPV 27,3 млн ₽, IRR 21,6%, окупаемость 96 мес), риски, инвестзаключение;
  использует 7 инвест-полей из заказа.

## Статусы генерации (п. 8.3 ТЗ)

«Заказ создан» → «Ожидает оплаты» → «Оплачен» → «Передан в обработку» →
«Сбор исходных данных» → «Выполняется анализ» → «Формируется PDF» → «Готово».
Плюс «Ошибка генерации» и «Требуется вмешательство специалиста». Полный список —
`STATUSES` в `server/src/generation.js`.
