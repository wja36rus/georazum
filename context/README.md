## Краткий статус (2026-11-05)

- ✅ **Backend готов**: Express API, in-memory БД, генерация отчётов (мок),
  админка, уведомления. Smoke-тест `server/test.js` — **42/42 ✅**.
- ✅ **Frontend готов**: React 19 + TypeScript + Rspack, FSD, SCSS, SVG-компоненты.
  Typecheck — 0 ошибок, Vitest — **47/47 ✅** (37 базовых + 10 тестов мок-API),
  сборка зелёная.
- ✅ **Визард по User Journey**: 6 шагов, многоучастковые заказы, анкеты M/L,
  тип заказчика, контакты/согласия, экран проверки перед оплатой.
- ✅ **Личный счёт (кошелёк)**: ЛК «Счёт» — баланс, пополнение картой, история
  операций; оплата заказа со счёта; админ — балансы всех пользователей,
  история и пополнение техподдержкой.
- ✅ **GitHub Pages работает без бэкенда**: продакшен-сборка без `API_URL`
  автоматически включает мок-режим (`USE_MOCKS`) — данные сайта подставляются
  в браузере, сервер не нужен. См. `client/src/shared/api/mock/`.
- ✅ Корневой `README.md` и `.gitignore` актуализированы.

Проект функционально завершён (прототип с моками). Дальнейшие шаги — только
по явной просьбе (см. «Что осталось» в [`roadmap.md`](roadmap.md)).
