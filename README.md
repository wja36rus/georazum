# Гео Разум

**Цифровой интеллект территорий.** Демо веб-сервиса: по кадастровому номеру нейросеть анализирует участок (реестры, спутниковые снимки) и формирует PDF-отчет — ограничения, инфраструктура, инвестиционная концепция.

Демо-версия: откройте [index.html](index.html).

## Сценарии

1. **Авторизация → оформление заказа → получение отчёта.**
2. **Оформление заказа → получение отчёта.**

Личный кабинет участвует по касательной: в него ведут имя пользователя в шапке и кнопка на экране успешной оплаты (только для авторизованных).

## Экраны

- **Вход** (`index.html`) — точка входа: модалка «Войти» и старт заказа по кадастровому номеру.
- **Конструктор заказа** (`order.html`) — визард из 6 шагов: подтверждение участка → роль → комбо-модули → контакты → оплата → экран успеха. На успехе — «Посмотреть отчёт» и «Личный кабинет» (для гостя скрыта).
- **Отчёт** (`report-demo.html`) — образец PDF-отчёта: ограничения, инфраструктура, инвестиционные показатели, «Сохранить как PDF».
- **Личный кабинет** (`cabinet.html`) — профиль, баланс, пополнение, история запросов (со ссылками на отчёты) и платежей.

Всё остальное (маркетинговый лендинг, тарифы по ролям, B2B-форма, FAQ) из демо убрано.

## Дизайн

Макет намеренно монохромный и плоский: серый фон, primary-кнопки серые, остальные белые, без иконок, логотипов и скруглений. Раскладка (сетки, карточки, таблицы) сохранена.

## Запуск

### Сайт (без бэкенда)

Сайт статический — просто откройте `index.html` в браузере. Вход, заказы, оплата и пополнение работают на локальных моках.

### REST API (опционально)

```bash
cd api/express
npm install
npm start          # http://127.0.0.1:3001
```

### Сайт + API

Когда сервер запущен, сайт автоматически использует его: логин через `POST /api/login`, заказы через `POST /api/orders`, пополнение и истории — из API. Если сервер недоступен, сайт молча фолбэчится на локальные моки.
