# Гео Разум

SaaS-сервис формирования **аналитического заключения по земельному участку**
по кадастровому номеру. Пользователь выбирает уровень анализа (S / M / L),
оплачивает картой, сервис асинхронно собирает отчёт и выдаёт его для печати/PDF.

ТЗ: [`ГР ТЗ сайт.docx`](ГР%20ТЗ%20сайт.docx)

## Стек

| Часть | Технологии |
| --- | --- |
| Backend | Node.js + Express (чистый JS), in-memory БД, scrypt-пароли, мок-генерация отчётов |
| Frontend | React 19 + TypeScript (strict) + **Rspack**, FSD, SCSS (дизайн-токены), SVG-иконки как React-компоненты, react-router-dom v7, Vitest (unit) |
| Сборка/тесты | `@rspack/cli` + swc-loader · типчек `tsc --noEmit` · Vitest + jsdom |

Дизайн — по референсу дашборда, основные цвета **голубой и зелёный**
(палитра в [`context/design.md`](context/design.md)).

## Запуск

Требуется Node.js 18+ (проверено на Node 24). Два терминала:

**Терминал 1 — API:**

```sh
cd server
npm install
npm start          # http://127.0.0.1:4000
```

**Терминал 2 — клиент:**

```sh
cd client
npm install
npm run dev        # http://127.0.0.1:5173 (прокси /api → 4000)
```

Откройте http://127.0.0.1:5173.

## Проверки

```sh
cd server && npm test          # smoke-тест API: 32/32
```

### Что можно проверить руками

- **Сценарий заказа**: войти как Иван → «Новый анализ» → кадастровый номер
  `36:16:3405742:189` (уровень S), `36:34:1823050:441` (M) или
  `36:25:6945030:776` (L) → уровень → акцепт оферты → оплата картой
  `4111 1111 1111 1111`, срок `12/30`, CVV `123`, holder `IVAN IVANOV` →
  статус генерации (поллинг) → отчёт → «Скачать PDF» (печать).
- **Карта-отказ**: `0000 0000 0000 0000` → «Платёж отклонён банком» (HTTP 402).
- **Админка**: `/admin` — статистика, заказы (смена статуса), пользователи
  (блокировка), тарифы, генерации, редактирование оферты.
- **ЛК**: `/cabinet` — табы: обзор, заказы, отчёты, платежи, документы,
  профиль, поддержка.

## Что замокано (осознанный предел прототипа)

- База данных — in-memory (`server/src/db.js`): **рестарт сервера сбрасывает
  все данные**, включая незавершённые генерации.
- Платёжный шлюз, email-письма, кадастровый реестр и сама генерация отчёта —
  заглушки. Отчёт собирается по шаблону `buildReport` (уровни S/M/L).
- Подтверждение email — мок: аккаунт подтверждается автоматически.
- Прод-замена: PostgreSQL + Redis, JWT, BullMQ, реальный платёжный провайдер,
  кадастровые источники, SMTP.
