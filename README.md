# Гео Разум

**Цифровой интеллект территорий.** MVP веб-сервиса: по кадастровому номеру нейросеть анализирует участок (15+ реестров, спутниковые снимки) и за 10 минут формирует PDF-отчет — от скрытых ограничений и борщевика до инвестиционной концепции с финмоделью (NPV, IRR, окупаемость).

Демо-версия: откройте [index.html](index.html).

> Коммерческое предложение по выводу прототипа в продакшн — [kp.md](kp.md).

## Возможности

- **Лендинг** (`index.html`) — герой-блок с поиском участка, «как работает за 3 шага», ролевые тарифы (Дачник, Риэлтор, Инвестор, Юрист), пример инсайта из отчета, B2B/B2G-форма, FAQ.
- **Конструктор заказа** (`order.html`) — визард из 6 шагов: подтверждение участка → роль → комбо-модули → контакты → оплата → экран успеха. Валидация и маски ввода.
- **Личный кабинет** (`cabinet.html`) — профиль (имя, email, телефон), баланс, пополнение счёта, история запросов и платежей.
- **Демо-отчет** (`report-demo.html`) — образец PDF-отчета: ограничения, инфраструктура, инвестиционные показатели.
- **Анимации** — WOW.js (появление блоков при скролле), jQuery, адаптив (4/2/1 колонки).
- **Авторизация** — вход по email, имя/телефон — моки (это авторизация, а не регистрация). Сессия в `localStorage` (`georazum.user`): шапка показывает имя + кнопку «Выйти».
- **Офлайн-моки** — весь сайт работает без сервера: заказы, оплата, пополнение имитируются на клиенте.

## Запуск

### Сайт (без бэкенда)

Сайт статический — просто откройте `index.html` в браузере. Все формы, заказы
и оплата работают на локальных моках.

### REST API (опционально)

```bash
cd api/express
npm install
npm start          # http://127.0.0.1:3001
```

### Сайт + API

Когда сервер запущен, сайт автоматически использует его: логин через
`POST /api/login`, заказы через `POST /api/orders`, пополнение и истории —
из API. Если сервер недоступен, сайт не ломается и молча фолбэчится на
локальные моки (офлайн-режим).

## Проверки
